# Report writing

Use this skill for a durable report rather than a short chat answer.

1. Confirm the audience, question, time period, and requested decision.
2. Draft an outline with an executive summary, evidence, analysis, recommendation, limitations, and sources.
3. Keep facts, calculations, assumptions, and recommendations visibly distinct.
4. Cite external claims with descriptive Markdown links. Give tables clear headers and units.
5. Put the reusable report in `/work/reports/<descriptive-name>.md`. Keep supporting notes in the same directory and use relative links for workspace artifacts.
6. Re-read the report for unsupported claims, conflicting numbers, missing dates, and ambiguous ownership.
7. In chat, provide the report path, the main conclusion, and the most important uncertainty.
