# Responsive detail panes

Chat information, file previews and run details opt into `DetailPaneLayout`: desktop
widths of at least 1280px dock them alongside the still-interactive work area. Smaller
viewports retain modal details, and confirmation dialogs always remain modal.
Navigation has a persistent 64px icon stage with separate collapse/expand thresholds;
the chat list retains its own width preference. See
[verification](../../../docs/design/chat-detail-layout-results-2026-10-12.md).
