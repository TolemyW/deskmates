# @deskmates/testkit

Test doubles and fixtures shared by every package's tests. Only ever a `devDependency`. Never imported by production code.

- `src/fake-sdk/` — scripted stand-in for `query()` from the Agent SDK. Plays a script of assistant text, tool calls, and results; calls `hooks.PreToolUse` and `canUseTool` at the same points the real SDK does; honours `allow`, `deny`, `defer`, `resume`, and AbortSignal. A tool dropped by `disallowedTools` / `tools` never reaches the hook; `allowedTools` auto-allows named tools after hooks without hiding other tools. A hook that throws or runs past its matcher's `timeout` leaves no decision, so the call falls through to `canUseTool` — both as the real CLI behaves. For ADR-0023 it also plays `model_switch` (runs `hooks.PostModelSwitch`, then later turns are served and reported in `modelUsage` under the new model; default target is the first `options.fallbackModel` entry), `api_retry` (a `system` / `api_retry` message) and `fail` (an `error_during_execution` result). Its own tests compare its message shapes against the recorded S0 sequences in `spikes/s0/`, so drift from the real SDK shows up here first.
- `src/fake-provider/` — in-process `SandboxProvider` with fault injection (create fails, exec times out, sandbox vanishes). Its observable behaviour mirrors `packages/sandbox-docker`: no exec timeout unless the request carries one, partial output returned on a timeout, `injectEnv` replacing the whole env file, empty `cmd` and duplicate `create` rejected the same way.
- `src/fake-connector/` — an in-process connector speaking the ADR-0012 HTTP contract (describe, validate, submit, status, receipt) through a `fetch` function, so a T1 Gateway calls it with no socket. It checks its credential, rejects a submission against its capabilities schema with field-specific errors, lets a test script the effect class per operation (`setEffect`), executes once per `(contentHash, idempotencyKey)` and keeps its own execution log (`executed`, `executions`), and adds a receipt version on every `advance`. `contentHashOf` is sha256 of `canonicalJson` from contracts.
- `src/fake-integration-runtime/` — an in-process stand-in for the integration runtime of ADR-0013 (OpenConnector v1.7.0 as `spikes/openconnector/` recorded it), served through a `fetch` function. It implements the surface the Gateway's `integrations/runtime-adapter.ts` uses: admin-token routes for provider setup, API-key connections, runtime tokens with `allowedConnections` (rewritten whole by `PUT`, an empty list granting everything as in the real runtime), OAuth config and authorization start, the public `/oauth/callback` code exchange bound to `state`, and the MCP `tools/call` of the five meta-tools behind a runtime token. `execute_action` refuses an ungranted connection with `connection_not_allowed` before touching a credential and keeps an execution log (`executions`) that ledger counts are reconciled against. MCP answers come as a one-event SSE body by default, as v1.7.0 sends them (`mcpResponse: "json"` for plain JSON). The catalog (`catalog.ts`) holds the spike's ten Slack and Google Drive actions with their `operationType`, the destructive examples, the two Drive permission writes and the Gitea read actions run end to end; `gitea.list_my_repositories` returns the spike's repositories including the forged `</untrusted>` probe.
- `src/fake-openai/` — a scripted OpenAI Chat Completions server for the OpenAI Agents SDK runtime (ADR-0044) and the model proxy: `POST /v1/chat/completions`, streaming or not, one script step (text or tool calls) per request, every request recorded with the tools it offered.
- `src/injection-corpus/` — prompt-injection samples, each paired with the expected framework behaviour.
- `fixtures/` — JSON samples of bots, workspaces, approval rules, price tables, and run event streams. Contract tests use the same fixture on both sides of the sidecar protocol.

The golden site (Galaxy Ops Console) is not here: it is `packages/golden-site`, a standalone package run as its own container, so that nothing under test shares a process or dependency tree with it.
