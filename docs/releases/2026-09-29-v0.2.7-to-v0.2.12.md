# v0.2.7 to v0.2.12

2026-09-29, v0.2.7 to v0.2.12, each through the full pipeline (T2 21/21 on
Testbox, drain, backup, activation), about 15 minutes per release:
- v0.2.7: the egress proxy died on an unhandled EPIPE and restarted deny-all,
  and the Gateway never pushed the policy again; fixed in the proxy, and the
  Gateway now reapplies the policy (a no-op when unchanged) on every use of a
  cached sandbox.
- v0.2.8: @mention picker and "who this wakes" line in the composer.
- v0.2.9: v0.2.8's upgrade recreated `vendordb-pg-compat` without a clean
  Chromium exit; the stale `/profile/SingletonLock` named the old hostname,
  Chromium exited 21 on every boot and every run failed "container not
  healthy". Recovered by hand (lock removed from the stopped workspace's
  volume, restart healthy in 11 s); entry.sh now removes a stale lock.
- v0.2.10 and v0.2.11: failed runs show where they happened, and as one muted
  line once the bot has recovered; a run whose sandbox cannot be prepared is
  retried once before any model call.
- v0.2.12: the UI keeps the operator credential in the tab's sessionStorage
  across reloads (ADR-0006 amendment 2).
