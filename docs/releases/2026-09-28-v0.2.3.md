# v0.2.3

2026-09-28, v0.2.3 on Testbox: T2 20 of 21 files passed; the two
`m2-boundaries` reachability cases failed. Two more host facts:
- The T2 harness did not pass the deployment's resolver to its proxies, so
  under a fake-IP host the public cases could not resolve. It now reads
  `EGRESS_PROXY_DOH_URL` and `EGRESS_PROXY_DNS`, and `verify` passes them
  from `shared/.env`.
- The Mihomo TUN carries all outbound traffic, not only DNS (`ip rule`
  sends everything not from `lo` to its table), and its international path
  comes and goes: at 19:40 the host itself could reach www.baidu.com but
  not example.com or github.com, which had worked hours earlier. The
  reachability cases now fetch `DESKMATES_T2_PUBLIC_HOST` (default
  example.com); `verify` passes `T2_PUBLIC_HOST` from `shared/.env`
  (`www.baidu.com` on Testbox). With both, `m2-boundaries` passed 6/6
  there, including `*` reaching a public name through DoH while private
  addresses and IP literals stay denied.

**Open internet on Testbox therefore means domestic sites reliably and
international sites only when that desktop proxy happens to route them.**
